Important: How this version stores products

This beginner version keeps the original products in products.json and saves admin changes in your browser's localStorage. This makes the project easy to learn and works on GitHub Pages, but changes are not shared between different browsers or devices.

For a real online store where every visitor sees the same changes, the next step is connecting this exact admin panel to Firebase, Supabase or another database.
